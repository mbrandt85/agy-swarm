# Antigravity CLI Swarm Blueprint

A portable, token-optimized multi-agent orchestration boilerplate and ruleset for Antigravity CLI.

## Quick Bootstrap

Run this command inside any target repository to install the blueprint:

```bash
curl -sL https://raw.githubusercontent.com/mbrandt85/agy-swarm/main/bootstrap.sh | bash
```

## Features

- **Token Optimization:** Lightweight test and lint wrappers reducing agent token burn.
- **Context Boundaries:** Dedicated .geminiignore blocking locks, caches, and build output.
- **Strict Governance:** English-only enforcement, Conventional Commits, and mandatory QA gates.
- **ADR Scaffold:** Built-in Architecture Decision Records structure in docs/adr/.
